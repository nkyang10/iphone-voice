# Dictation Bridge（繁體中文）

**用 iPhone 講嘢，字就係出現喺 Windows 電腦 focus 嗰個視窗。**

## 開始用

**1. 喺電腦**

載入 `DictationBridge.exe` 行就得。全部安裝就係咁，冇安裝程式、冇額外執行環境、冇設定。
畫面中間附近會彈一個細面板。用嘅時候要開住佢唔好閂咗。

下載得一個檔案。手機要嘅證書係你自己部電腦第一次行嘅時候開出嚟㗎，所以每人都有
啱自己部機嗰一份。

**2. 喺手機**

用後置鏡頭掃面板上面嘅 QR 圖碼，撳彈出嚟嘅連結就會開到網址，類似
`https://192.168.1.162:8080/`。

如果鏡頭掃唔到，QR 圖碼隔籬就寫住同一個網址，自己入去 Safari 打都一樣。

手機會叫你裝一個證書，照撳就得。呢一步**只會出現一次**，詳細步驟喺下面
[設定手機](#設定手機)。

**3. 撳 Start listening**

如果問就俾麥克風權限。由呢一刻開始，手機唔再需要你理。

**4. 講嘢**

喺電腦撳 **Ctrl+Alt+D`，等面板顯示 **LISTENING**，然後開始講。你講乜就會打落你手
機做緊嘅任何一個視窗。再撳一次就暫停。

就係咁。你可以放低部電話唔理。

## 唯一要記住嘅事

面板開機係 **PAUSED** 嘅，而且你未撳鍵之前佢乜都唔會打。

呢個係特登咁。如果一開就打字，重啟一次就可以唔小心將啲字打落你啱啱開緊嘅視窗。所以暫停
期間你講嘅嘢會靜靜哋**排隊**，一撳就即刻打出去。排隊嘅嘢喺面板睇得到，所以唔會漏。

## 日常使用

| | |
| --- | --- |
| 開始／停止打字 | **Ctrl+Alt+D**，或者撳面板個掣 |
| 喺手機開網頁 | 掃面板上面嘅 QR 圖碼 |
| 叫返面板出嚟 | 撳右下角圖示 |
| 移動面板 | 拖佢。佢記得你擺咗喺邊 |
| 改快捷鍵 | 展開面板，撳 **Change hotkey**，再撳新組合 |
| 睇返啱啱講咗乜 | 收到即刻顯示喺面板 |
| 如果埠俾人用咗 | 行 `DictationBridge.exe --port 8099` |

如果你唔想撳鍵，直接撳面板個暫停掣一樣得。

### 講粵語或者中文

喺手機嗰頁用下拉選語言，預設係粵語。

如果部 iPhone 唔接受嗰個語言，頁面會自動試下一個，並且話你知最後用咗邊個。粵語會先試
`zh-HK`，然後 `yue-HK`，再 `zh-TW`。

> **提提你：** 手機自己嘅語音輸入設定會影響結果。如果粵語變咗普通話，去
> 設定 > 一般 > 鍵盤 > 語音輸入 改成粵語。

### 自動鎖定

設定 > 顯示與亮度 > 自動鎖定 改成**永不**。

電話熄咗螢幕，頁面就會暫停，唔再聽。呢個係最值得改嘅設定。

## 佢會產生嘅檔案

所有嘢都放喺 exe 旁邊嘅 `data\` 資料夾，第一次行就會開。exe 本身唔會俾人改。成個資料夾
刪咗就等於全部重設，連證書都冇咗。不過程式行緊嘅時候唔好刪。

淨係有一個檔案重要：**`data\dictation-bridge.cer`**，就係要裝去手機嗰張證書。程式
一開就會話你知完整路徑喺邊。

## 私隱

你講嘅嘢係 **Apple** 轉錄嘅，因為 Safari 嘅語音輸入本來咁。文字經你自己個網絡送去自己部
電腦。冇送畀我哋，亦都冇送去邊度。

有一點要老實講：同一個網絡上嘅人如果知道咗 session token，就可以打字落你個視窗。屋企網絡
冇問題，共用或者公眾 WiFi 就要留意。

## 已知限制

- 電話畫面要 keep 住亮同未鎖。
- 打唔入以**管理員**身份執行嘅程式。Windows 唔准跨權限層級做模擬輸入，出事時 log 會講。
- 如果部電腦 IP 變咗證書冇列嘅一個，證書要再裝多次。通常唔會發生，因為大部分網絡都會
  派返同一個地址。
- 要 iOS 14.5 或以上。iOS 上嘅 Chrome 同 Firefox 理論上都得，但 Safari 先係測試過嗰個。

## 設定手機

iOS 淨係喺安全頁面先會開語音輸入，而且佢個 Safari 冇「繼續前往」嗰個掣。所以電腦會
行一個細細嘅 HTTPS 伺服器，你信佢一次證書就得。

**攞你嘅證書。** 先行一次程式，喺佢開出嚟嘅 `data` 資料夾入面搵
`data\dictation-bridge.cer`。程式一開就會印出完整路徑。

**再傳去手機。** 用 AirDrop、電郵、乜都得。喺手機撳開佢。一定要係你自己嗰份，因為份證書
對應嘅係開佢嗰部電腦嘅網絡地址。

**安裝：**

1. **設定 > 一般 > VPN 與裝置管理**
2. 撳 Dictation Bridge 嗰個描述檔
3. 撳**安裝**

**然後俾佢權限。** 呢第二步好多人會漏咗，漏咗個 app 就好似壞咗：

4. **設定 > 一般 > 關於本機 > 信任證書設定**
5. 開啟 **Dictation Bridge**

**開個頁面**：掃面板上面嘅 QR 圖碼，或者手打 QR 圖碼隔籬嗰個網址。

### 一次過，之後唔使再嚟

電腦會保留住張證書，所以重啟電腦或者重開程式都唔使再裝一次。

張證書同時有 `dictation-bridge.local` 呢個名喺入面。如果手機解析得到，可以改用
`https://dictation-bridge.local:8080/`，同一張證書就換咗網絡都一樣用得着。不一定每個網絡
都解析得到，所以 IP 嗰個最穩，名只係額外着數。

## 有問題搵我

**頁面話冇語音辨識。**
證書未受信任。返去做上面第 4 步，同埋確認你開嘅係 `https://` 而唔係 `http://`。

**開始好用，講完一段時間之後靜咗。**
撳一次 Ctrl+Alt+D。如果就醒得返，係你個 iOS 每次都要撳一下先肯重新開始，而唔係自己重啟。
話我知，我加個「撳一下繼續」掣。

**頁面有顯示你講咗乜，但乜都冇打。**
睇下面板係咪寫住 **LISTENING**，同埋撳-hotkey 撳咗兩次。

**目標程式乜都冇出現。**
睇下佢係咪以管理員身份執行。開 `data\dictation-bridge.log`，如果係呢個問題，log 會寫
`SendInput sent 0/44`。

**地址變咗，證書被換咗。**
面板會顯示新地址。將新嘅 `data\dictation-bridge.cer` 傳去手機再裝一次。

**搞掂晒都唔得。** 開 `data\diagnostics.log`。喺手機頁撳 **Send to desktop**，log 就會話
我哋知語音辨識做緊乜。佢記錄事件同錯誤碼，唔會記你講咗乜，除非你撳咗*包括說話內容*。
