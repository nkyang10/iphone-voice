# Dictation Bridge（繁體中文）

**用 iPhone 講嘢，字就係出現喺 Windows 電腦 focus 嗰個視窗。**

## 開始用

**1. 喺電腦**

載入 `DictationBridge.exe` 行就得。全部安裝就係咁，冇安裝程式、冇額外執行環境、冇設定。
畫面中間附近會彈一個細面板。用嘅時候要開住佢唔好閂咗。

下載得一個檔案。手機要嘅證書係你自己部電腦第一次行嘅時候開出嚟㗎，所以每人都有
啱自己部機嗰一份。

**2. 喺手機**

用後置鏡頭掃面板上面嘅 QR 圖碼，撳彈出嚟嘅連結就會開到頁面，**順便將部手機同呢部電腦配對**：
個碼除咗網址（類似 `https://192.168.1.162:17123/`），仲帶住一條配對密鑰。

QR 圖碼隔籬都寫住個網址，不過自己手打就淨係開到頁面、配對唔到，頁面會話你知。如果鏡頭掃唔到，
喺面板撳 **Copy pairing link**，再將條連結傳去手機。

手機會叫你裝一個證書，照撳就得。呢一步**只會出現一次**，詳細步驟喺下面
[設定手機](#設定手機)。

**3. 撳 Start listening**

如果問就俾麥克風權限。由呢一刻開始，手機唔再需要你理。

**4. 講嘢**

直接開始講。你講一句，佢就即刻打落去，唔係等你講完成句先打。

就係咁。你可以放低部電話唔理。

## 唯一要記住嘅事

**頁面收緊音嘅時候，你講嘅每一句都會直接打落而家個焦點視窗。** 冇暫停、冇排隊、冇鍵。

呢個就係而家全部嘅設計：**手機頁面嘅 Start 掣係唯一嘅開關**，電腦嗰邊一樣。撳一下
開始打字，再撳一下停。

以前其實安全啲。電腦有一粒 **Ctrl+Alt+D**，而且面板開機係暫停，所以重啟一次唔會將啲
字打落你啱啱開緊嘅視窗。而家呢第二個掣冇咗，所以有一句要老實講清楚：**如果你將收緊音
嘅頁面擺喺枱面、電話螢幕向上，佢會聽到房入面嘅聲而且打出嚟。** 將部電話擺喺聽唔到房
間嘅位置，唔用就撳 Stop。

### 點睇 Start 掣

個掣上面嘅字**永遠唔郁**，一直都係 **Start listening**。變嘅係佢撳唔撳得到，而家呢
樣嘢跟住咪高峰：

| 個掣 | 意思 |
| --- | --- |
| 藍色、撳得到 | 停咗，或者頁面放棄咗。撳一下開始。 |
| 灰咗（撳唔到） | 頁面仲喺度試緊收緊音，你講嘢就會打落去。唔使理。 |

一旦真係唔聽得，個掣自己會返嚟：咪高峰被拒絕、每一種語言都試過、或者手機接受咗好幾次
收音但一直都冇開過咪高峰嗰啲情況。只有呢啲時候撳先有用，所以都只係呢啲時候先會出現
可撳嘅掣。所以**灰咗就係一個意思：佢仲做緊嘢**。

上面粒圓點同一行字就講細節：*idle*、*starting (zh-HK)*、*listening*、*recovering from
stall*。

### 點解唔等你講完先打

頁面一收到收音器出嚟嘅每個半成品結果就即刻送，淨係留返最後十個字唔送。區網送幾十字元
同送個封包頭差唔多，所以拎住啲字唔放冇著數。

留嗰十個字係有原因嘅。Safari 對你啱啱講完嗰幾個字未算完：佢會喺你講完大約半秒之後
改返你而家講緊嗰個字（*"recognize spee"* 變成 *"recognized speech"*）。而已經打咗出畫面
嘅字拎唔返，所以遲呢少少送，就等佢喺字仲留喺手機嗰陣改完。實際上大部分聽錯嘅字
**根本唔會出現喺畫面上**。

呢個 delay 唔會永久嘅：一旦有 final result 就即刻放，唔會俾你講完嗰句慢吞吞；而停頓、
收音結束同撳 Stop 都會即刻放。最多只係慢咗一句說話尾十個字。

如果個修正真係改咗已經打咗嘅字（即係 iOS 改嘅位置超過十個字之前），嗰個字就會錯咗。頁面
唔會送個改動，所以唔會打兩次，句子亦都繼續依次序落去。

| 開始／停止打字 | 手機頁面嘅 **Start listening** |
| 睇下係咪真係收緊音 | Start 掣：**灰咗**就係咪高峰開住 |
| 喺手機開網頁 | 掃面板上面嘅 QR 圖碼，順便配對埋 |
| 取消所有手機嘅配對 | 喺面板撳右掣揀 **Reset phone pairing...**，再掃新嘅 QR 圖碼 |
| 叫返面板出嚟 | 撳右下角圖示 |
| 托盤圖示做到嘅嘢 | 喺面板任何位置撳右掣，選單一樣 |
| 移動面板 | 拖佢。佢記得你擺咗喺邊 |
| 睇返啱啱講咗乜 | 收到即刻顯示喺面板 |
| 如果埠俾人用咗 | 行 `DictationBridge.exe --port 8099` |

### 講粵語或者中文

喺手機嗰頁用下拉選語言，預設係粵語。

如果部 iPhone 唔接受嗰個語言，頁面會自動試下一個，並且話你知最後用咗邊個。粵語會先試
`zh-HK`，然後 `yue-HK`，再 `zh-TW`。

> **提提你：** 手機自己嘅語音輸入設定會影響結果。如果粵語變咗普通話，去
> 設定 > 一般 > 鍵盤 > 語音輸入 改成粵語。

### 自動鎖定

設定 > 顯示與亮度 > 自動鎖定 改成**永不**。

電話熄咗螢幕，頁面就會暫停，唔再聽。呢個係最值得改嘅設定。

## 佢會產生嘅檔案

所有嘢都放喺 exe 旁邊嘅 `data\` 資料夾，第一次行就會開。exe 本身唔會俾人改。成個資料夾
刪咗就等於全部重設，連證書都冇咗。不過程式行緊嘅時候唔好刪。

淨係有一個檔案重要：**`data\dictation-bridge.cer`**，就係要裝去手機嗰張證書。程式
一開就會話你知完整路徑喺邊。

另外 `data\pairing-key.txt` 係配對密鑰，有咗佢就可以喺呢部電腦打字，所以**千祈唔好**連同
錯誤報告一齊傳出去。刪咗佢或者用 **Reset phone pairing...**，就會取消所有手機嘅配對。

## 私隱

你講嘅嘢係 **Apple** 轉錄嘅，因為 Safari 嘅語音輸入本來咁。文字經你自己個網絡送去自己部
電腦。冇送畀我哋，亦都冇送去邊度。

淨係配對咗嘅手機先打得字。配對密鑰收喺 QR 圖碼入面 `#` 後面嗰段，瀏覽器永遠唔會將呢段送去
任何伺服器，電腦亦都唔會派出去：同一個 WiFi 嘅其他裝置開到個網址，都只係攞到個頁面，佢發出嘅
每個請求都會被拒絕。log 入面冇密鑰，亦都唔再記錄你講咗乜，淨係記低打咗幾多個字。

有一點要老實講：睇到 QR 圖碼、拎到部手機、或者拎到電腦 `data\` 資料夾嘅人，都有條密鑰。喺共用
或者公眾網絡，有其他人喺附近就收埋個面板；唔再信得過某部手機，就用 **Reset phone pairing...**
截斷佢。

## 已知限制

- 電話畫面要 keep 住亮同未鎖。
- 打唔入以**管理員**身份執行嘅程式。Windows 唔准跨權限層級做模擬輸入，出事時電話會話你知。
- 佢只會打字，唔會撳掣：冇 Enter、冇 Tab、冇 Backspace。電話送過嚟嘅換行會變成一個空格，
  因為 Enter 會send走條訊息或者交咗張表格。
- 如果部電腦 IP 變咗證書冇列嘅一個，證書要再裝多次。通常唔會發生，因為大部分網絡都會
  派返同一個地址。
- 要 iOS 14.5 或以上。iOS 上嘅 Chrome 同 Firefox 理論上都得，但 Safari 先係測試過嗰個。

## 設定手機

iOS 淨係喺安全頁面先會開語音輸入，而且佢個 Safari 冇「繼續前往」嗰個掣。所以電腦會
行一個細細嘅 HTTPS 伺服器，你信佢一次證書就得。

**攞你嘅證書。** 先行一次程式，喺佢開出嚟嘅 `data` 資料夾入面搵
`data\dictation-bridge.cer`。程式一開就會印出完整路徑。

**再傳去手機。** 用 AirDrop、電郵、乜都得。喺手機撳開佢。一定要係你自己嗰份，因為份證書
對應嘅係開佢嗰部電腦嘅網絡地址。

**安裝：**

1. **設定 > 一般 > VPN 與裝置管理**
2. 撳 Dictation Bridge 嗰個描述檔
3. 撳**安裝**

**然後俾佢權限。** 呢第二步好多人會漏咗，漏咗個 app 就好似壞咗：

4. **設定 > 一般 > 關於本機 > 信任證書設定**
5. 開啟 **Dictation Bridge**

**開個頁面**：掃面板上面嘅 QR 圖碼。個碼帶住配對密鑰，所以要掃，唔好手打網址。

### 一次過，之後唔使再嚟

電腦會保留住張證書，所以重啟電腦或者重開程式都唔使再裝一次。

張證書同時有 `dictation-bridge.local` 呢個名喺入面。如果手機解析得到，可以改用
`https://dictation-bridge.local:17123/`，同一張證書就換咗網絡都一樣用得着。不一定每個網絡
都解析得到，所以 IP 嗰個最穩，名只係額外着數。

## 有問題搵我

**頁面話 "not paired with this PC"。**
個頁面開嘅時候冇配對密鑰，通常係因為手打咗網址，或者部手機掃完之後電腦重設咗配對。再掃一次
面板上面嘅 QR 圖碼就得；有手機俾拒絕緊嘅時候，面板會顯示 *phone not paired: scan the QR code*。
期間講咗嘅嘢會留喺手機，配對好之後就會打出嚟。

**頁面話冇語音辨識。**
證書未受信任。返去做上面第 4 步，同埋確認你開嘅係 `https://` 而唔係 `http://`。

**開始好用，講完一段時間之後靜咗。**
呢個正常。收音器會一直開住等你，同打電話一樣，個掣亦一直灰住。唔想等就撳多次
**Start listening**。

**頁面有顯示你講咗乜，但乜都冇打。**
睇下個 Start 掣。灰咗就代表咪高峰開住、頁面有喺送，咁問題就喺電話同電腦
之間：睇下係咪寫住 *connected to desktop*，同埋有冇嘢仲卡住未送。

**有個字打錯，跟住下一個字都錯。**
預期之內，而且冇得救：文字係一邊聽一邊打，打咗嘅字拎唔返。iOS 大概會喺你講完一秒後
先改返佢聽錯嗰個字嗰陣佢已經上咗畫面。頁面唔會send嗰個改動，所以一個錯字唔會蔓延成
一句錯嘅。

**目標程式乜都冇出現。**
電話頁面會即刻話你知點解：前面嗰個視窗以管理員身份執行、冇視窗有焦點（部電腦鎖咗或者
瞓咗），或者焦點喺 Dictation Bridge 面板度。撳返入你想打字嘅視窗，再講一次。冇打到嘅字
喺電話嘅記錄度會畫低橫線，唔會自己再send，因為到時佢會打落當時有焦點嘅視窗。面板嘅
狀態行都會講幾秒。

**地址變咗，證書被換咗。**
面板會顯示新地址。將新嘅 `data\dictation-bridge.cer` 傳去手機再裝一次。

**搞掂晒都唔得。** 開 `data\diagnostics.log`。喺手機頁撳 **Send to desktop**，log 就會話
我哋知語音辨識做緊乜。佢記錄事件同錯誤碼，唔會記你講咗乜，除非你撳咗*包括說話內容*。
