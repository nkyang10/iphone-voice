# Dictation Bridge（简体中文）

**在 iPhone 上说话，字就出现在 Windows 电脑当前聚焦的窗口里。**

不用打字，不用凑到键盘，不用停下手上的事。拿着手机，按一个键，说就行。

## 开始使用

**1. 在电脑上**

下载 `DictationBridge.exe` 运行即可。安装就这一步：没有安装程序，没有运行环境，没有配置。
屏幕中间附近会出现一个小面板。

**2. 在手机上**

打开面板显示的地址，形如 `https://192.168.1.162:8080/`。

手机会要求你安装一个证书，按提示操作即可。这一步**只会有一次**，详细步骤见下面的
[设置手机](#设置手机)。

**3. 点 Start listening**

如果询问就授予麦克风权限。从这里开始，手机不再需要你操作。

**4. 说话**

在电脑上按 **Ctrl+Alt+D**，等面板显示 **LISTENING**，然后开始说。你说的话会打进你正在
使用的窗口。再按一次暂停。

就这样。你可以把手机放下不用管。

## 唯一需要理解的事

面板启动时是**暂停**状态，在你按键之前它不会输入任何东西。

这是有意为之。如果一启动就输入，重启一次就可能把文字打进你恰好打开的窗口。所以暂停期间
你说的内容会安静地**排队**，按键的瞬间立即输入。队列在面板里可见，不会丢失。

## 日常使用

| | |
| --- | --- |
| 开始／停止输入 | **Ctrl+Alt+D**，或点击面板按钮 |
| 再次唤出面板 | 点击托盘图标 |
| 移动面板 | 拖动它。它会记住你放的位置 |
| 修改快捷键 | 展开面板，点 **Change hotkey**，按下新组合 |
| 查看刚才说了什么 | 收到后立即显示在面板上 |
| 如果端口被占用 | 运行 `DictationBridge.exe --port 8099` |

如果你不想碰键盘，直接点面板上的暂停按钮同样可以。

### 说粤语或中文

在手机页面的下拉菜单里选择语言，默认是粤语。

如果你的 iPhone 不接受某个语言，页面会安静地尝试下一个，并告诉你最终用的是哪一个。粤语
会先尝试 `zh-HK`，然后 `yue-HK`，再 `zh-TW`。

> **提示：** 手机自身的听写语言设置会影响结果。如果粤语输出成了普通话，请在
> 设置 > 通用 > 键盘 > 听写 中改为粤语。

### 自动锁定

设置 > 显示与亮度 > 自动锁定 设为**永不**。

手机屏幕锁定后页面会挂起并停止聆听。这是唯一值得修改的设置。

## 它会产生的文件

所有内容都放在 exe 旁边的 `data\` 文件夹里，首次运行就会创建。exe 本身不会被修改。
删除整个文件夹即可完全重置，包括证书。

只有一个文件对你重要：**`data\dictation-bridge.cer`**，即需要安装到手机上的证书。
程序启动时会打印它的完整路径。

## 隐私

你的语音由 **Apple** 转录，因为 Safari 的听写就是这样工作的。文本通过你自己的网络
发送到你自己的电脑。不会发送给我们，也不会发送到任何其他地方。

有一点需要如实说明：同一网络上知道会话令牌的人可以向你的窗口输入内容。在家庭网络中
没有影响，但在共享或公共 WiFi 上请留意。

## 已知限制

- 手机屏幕需要保持点亮且未锁定。
- 无法输入以**管理员**身份运行的程序。Windows 禁止跨权限级别模拟输入，发生时日志会
  明确提示。
- 如果电脑的 IP 地址变成证书未列出的地址，需要重新安装一次证书。通常很少发生，因为
  大多数网络会分配相同的地址。
- 需要 iOS 14.5 或更新版本。iOS 上的 Chrome 和 Firefox 理论上可用，但 Safari 是实际
  测试过的。

## 设置手机

iOS 只在安全页面上开放语音听写，而且它版本的 Safari 没有「仍要继续」按钮。因此电脑会
运行一个小型 HTTPS 服务器，你需要信任它的证书一次。

**将证书发送到手机。** 位于 `data\dictation-bridge.cer`，程序启动时会打印完整路径。
用 AirDrop、邮件或任何方式发送都行。在手机上点击它。

**安装：**

1. **设置 > 通用 > VPN 与设备管理**
2. 点击 Dictation Bridge 描述文件
3. 点击**安装**

**然后授予信任。** 第二步是很多人会漏掉的，漏掉后应用看起来像是坏了：

4. **设置 > 通用 > 关于本机 > 信任证书设置**
5. 打开 **Dictation Bridge**

**打开页面**，使用面板显示的地址。

### 只需一次

电脑会在多次运行之间保留证书，因此重启电脑或重新启动应用都不需要重复这个步骤。

证书同时也包含 `dictation-bridge.local` 这个名称。如果你的手机能解析它，可以使用
`https://dictation-bridge.local:8080/` 代替 IP 地址，同一张证书在任何网络下都能继续
使用。它并非在所有网络都能解析，所以请把 IP 地址作为可靠选项，域名作为额外便利。

## 遇到问题时

**页面提示没有语音识别。**
证书未受信任。请回到上面的第 4 步，并确认你打开的是 `https://` 而不是 `http://`。

**开始正常，停止说话一段时间后安静下来。**
按一次 Ctrl+Alt+D。如果这样能恢复，说明你的 iOS 每次都需要点击才能重新开始，而不是
自动重启。告诉我，我会加一个「点击继续」按钮。

**页面显示了你说的话，但没有输入。**
检查面板是否显示 **LISTENING**，以及你是否按了两次快捷键。

**目标程序里没有出现任何内容。**
检查它是否以管理员身份运行。打开 `data\dictation-bridge.log`，如果是这个问题，日志
会显示 `SendInput sent 0/44`。

**地址改变后证书被替换。**
面板会显示新地址。将新的 `data\dictation-bridge.cer` 发送到手机并重新安装。

**仍然无法解决。** 打开 `data\diagnostics.log`。在手机页面上点击 **Send to desktop**，
日志会告诉我们语音识别具体在做什么。它记录事件和错误代码，不记录你说了什么，除非你
勾选 *include spoken words*。
